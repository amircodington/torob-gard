# ترب‌گرد · Torob Gard

«از چی بخرم تا از کجا بخرم!»

A Persian, phone-first companion for in-person shopping in downtown Tehran's electronics district: it helps you decide what to buy and where to buy it, using Torob data.

## Commands

`make dev` · `make hooks` · `make down` · `make check` · `make test-api` · `make ingest` · `make psql`

`docs/` is the spec; start at `CLAUDE.md`.
