# Decisions

Numbered. Do not reverse one without asking Mohammad.

1. **2026-10-22 — Stack = Option A.** `web/` Next.js 16 + TS + Tailwind v4 (pnpm); `api/` Django 5.2 + Ninja (uv) for data + team admin; `agent/` FastAPI (uv) for the agent loop; PostgreSQL 16 + pgvector + PostGIS; Redis 7; Docker Compose; Makefile `dev / check / push-test`.
   - 2026-10-22 note: db image is `imresamu/postgis:16-3.5` (arm64 build of PostGIS 3.5 / PG16); `postgis/postgis:16-3.5` is amd64-only.
2. **2026-10-22 — LLM and embeddings through BoxAPI** (`https://ai.boxapi.ir/ai/v1`, OpenAI-compatible, Bearer auth, SSE streaming). One `LLMClient` behind the OpenAI wire format so any model id can be swapped by env var. Dev default: `anthropic/claude-sonnet-5` for the agent, `anthropic/claude-haiku-5.5` for cheap classification, `qwen/qwen3-embedding-8b` for embeddings (cheap, strong multilingual). Tool calling must be verified on BoxAPI in P0 (docs don't mention it).
3. **2026-10-22 — Team.** Mohammad builds the software. Two university students do R&D and testing: data QA, evals, field checks, docs. The task book is written for them.
4. **2026-10-22 — Working name «راهبر خرید».** Superseded by 9.
5. **2026-10-22 — Data = the Starcoach v16 dataset** (`docs/starcoach-dataset-v16-cap300-csv/`): 6,476 Tehran shops (all geocoded, 59% inside a named pasazh, 65% with a floor in the address), 225,903 products, 316,423 offers. It is downtown electronics / lighting / mobile / industrial, centred on Ferdowsi, Sheikh Hadi (Lalezar), Baharestan. **First target area: the Lalezar–Ferdowsi electronics district** (Aladdin 1/2, Charsoo, Bushehri, Ettehadieh pasazhs), not fashion malls. Palladium/Kourosh ideas are parked.
   - 2026-10-22 note: loaded: 315,665 offers after dropping null price/date rows (P0).
6. **2026-10-22 — Context: this is a competition challenge sponsored by Torob (Starcoach).** Product decisions optimise for a convincing, working demo on the given dataset first; the business ideas in the brainstorm are Tier 3.
7. **2026-10-22 — No amox-os.** Repo conventions come from `diarman` and `future-mission-2d` directly.
8. **2026-10-22 — Visual direction = the reference UI Mohammad sent** (fitness-app style): light mode only, warm near-white ground with a peach radial glow, white cards with big radii and an orange-tinted shadow, one orange (#ee8a2a) for every active state, a black sheet for route / in-shop mode with brown and plum stat cards. Vazirmatn with thin+bold mixing instead of italics; Lalezar dropped. Source: `docs/design/brand/`, mockups `docs/design/ui-mockups.html`.
9. **2026-10-22 — Name = ترب‌گرد (Torob Gard).** Tagline «از چی بخرم تا از کجا بخرم!». Repo folder `~/Workspace/torob-gard`, package/service prefix `torob-gard` / `torobgard`. Replaces decision 4.
10. **2026-10-22 — The UX prototype is the product spine.** `docs/torob-gard-ux-prototype/` defines the journey: consult chat → decision desk (3 tiers + compare) → store radar (map/list, filters, sort, store sheet) → Plan B recovery → pre-trip checklist. Production keeps its flow, copy and honesty rules and replaces `data/demo.ts` with the Starcoach data; its pure logic (`ranking.ts`, `fa.ts`) is ported with tests. Plan: `docs/PLAN.md`.
11. **2026-10-22 — Visual = decision 8 + the prototype's mascot.** Orange `#ee8a2a` active state, peach glow, black sheet stay (decision 8 is newer than the prototype's Torob-red tokens). The red-sprout mascot is adopted as the brand character and app icon. Prototype colours (`#d92d2b`, cream, mint) are not carried over.
12. **2026-10-22 — Redesign: icons and motion.** lucide-react for icons (bundled, 1.75 stroke); the motion system in `web/src/app/globals.css` + `web/src/lib/motion.ts` widens the brand README's "four moments" rule at Mohammad's request («کلی انیمیشن جذاب»). Decisions 8 and 11 unchanged.
