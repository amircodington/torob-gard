# Redesign — Responsive, Icons, Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mohammad's request (2026-10-22, in Persian): «ریدیزاینی که لایه‌ی واکنش‌گرا رو برای گوشی و دسکتاپ بهتر کنه؛ کلی آیکون و انیمیشن جذاب اضافه کن». The phone (360–430 px) stays the primary design and gets more alive; tablet and desktop get real layouts instead of a stretched phone column; one bundled icon set; one motion system.

**Architecture:** No new pages, no new data. Three shared layers land first (motion tokens + `lib/motion.ts`, icons, the `page` container + breakpoints), then the shared `Sheet`, then one screen per task. CSS does every entrance, press and hover; GSAP (already installed, 3.15) does only what CSS cannot: the draggable/side sheet, Flip re-ordering, the sliding chip pill, the map pin drop, count-ups, and the two mascot/success timelines.

**Tech Stack:** as P1, plus `lucide-react` (the only new dependency) and the GSAP plugins that ship inside the installed `gsap` package (`gsap/Flip`, `gsap/CustomEase`, both free since 3.13). No `@gsap/react`: the codebase already uses `gsap.matchMedia()` + `revert()` in `useLayoutEffect` (StoreSheet, WalkSheet); keep that one pattern.

**Spec:** `docs/PLAN.md` §2 (journey + honesty rules), §3 (pages); `docs/design/brand/README.md` (decision 8 look, decision 11 mascot); screenshots of the P1 build at 390 and 1440 taken 2026-10-22 (what this plan fixes is listed per task under "Why").

## Global Constraints

- **Never reverse decisions 8 and 11.** Light only; `paper` + blush glow; white cards, no borders, `shadow-card`; `orange` `#ee8a2a` is the only active colour; black `panel` sheet with `panel-brown`/`panel-plum` stat cards; Vazirmatn thin+bold mix; the red-sprout mascot, one per screen, never on orange or on the black sheet. No new colours: icons use `ink`, `ink-muted`, `orange`, `verified`, `signal`, `on-dark` only.
- **Brand README motion rule is widened, not broken.** Today it says "Four moments animate. Nothing else." Task 1 rewrites that section to the motion system below (Mohammad asked for it) and adds decision 12; the four P1 moments (sheet spring/drag, active chip slide 220 ms, bars growing with 40 ms stagger, reply streaming) stay and are the first entries.
- **Honesty rules 1–6 stay visible in every new layout** (price age + «ممکن است تغییر کرده باشد» past 60 days, «موجودی نامشخص», «ثبت نشده», «احتمالاً», no outliers, footer credit). A layout may move them, never hide them behind a hover, a collapsed panel or a breakpoint. Task 1 adds `e2e/honesty.spec.ts` so every later task proves it.
- **Breakpoints (Tailwind v4 defaults, no custom ones):** base = phone 360–767 (designed at 390); `md` 768–1023 = tablet; `lg` ≥ 1024 = desktop; `xl` ≥ 1280 only widens gutters. The page container is one utility, `page` (Task 1): `max-w-md` → `md:max-w-2xl` → `lg:max-w-6xl`.
- **Motion:** transform/opacity only (plus `scale`/`translate` CSS properties); every animation has a `prefers-reduced-motion: reduce` variant (opacity-only or none); nothing loops forever except the existing anchor ping on the map; no animation on a keyboard action; UI durations ≤ 320 ms except the two rare moments (landing hero, trip success) at ≤ 600 ms; stagger 40–60 ms and capped at 8 items (later items appear instantly). Entrances use CSS (runs off the main thread on a low-end Android); GSAP only where listed.
- **No runtime loads from outside Iran:** icons are compiled into the bundle (lucide-react is ESM, one module per icon, and is in Next 16's default `optimizePackageImports`); no icon fonts, no CDN, no sprite fetch.
- **RTL icon rule:** author every icon in its LTR meaning; icons that imply direction or progress (`ArrowRight`, `ArrowLeft`, `ChevronRight`, `ChevronLeft`, `SendHorizontal`, `Undo2`, `LogOut`) get `className="flip-rtl"` (Task 1 utility) so they mirror under `dir="rtl"`. Never mirror: clocks, `RotateCcw` (reset), `Footprints`, checkmarks, phone, map pin, store, camera, battery, media/brand-like glyphs, numbers. So "forward/next" = `ArrowRight flip-rtl` (renders pointing left), "back" = `ArrowLeft flip-rtl` (renders pointing right).
- **P2 files:** `web/src/app/start/page.tsx` and `web/src/components/radar/StoreSheet.tsx` gain agent chat and a price-check card in P2. This plan restyles **around** them: layout goes into new wrappers (`ConsultFrame`, `ui/Sheet`), icons arrive through shared components (`Btn`, `FreshBadge`, `StockBadge`). Edits inside those two files are limited to what each task names (≤ 25 changed lines each) so the P2 rebase is trivial.
- Do not touch `agent/`, `api/`, `Makefile`, `docker-compose*`, Dockerfiles.
- UI skills while building: `emil-design-eng` per screen, `apple-design` for the sheet and gestures, `animate` + `gsap-core`/`gsap-plugins` for motion, `mobile-native` before the gate, `break-ui` on TierCard, ShopRow and the side sheet.
