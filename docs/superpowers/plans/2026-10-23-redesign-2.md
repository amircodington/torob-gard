# Redesign 2 — Dana, new mascot, bands, much more motion

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Mohammad's second redesign pass (decision 13): Dana font, the new 3D radish mascot everywhere, a landing with clearly separated, higher-contrast sections and tighter spacing, a fixed wordmark with logo motion, page loaders, and many more soft, interactive animations (hover, press, list-in, icons) on every page.

**Why (Mohammad, verbatim gist):** landing background too flat, sections not separated, everything one blob, contrast low, too much space between sections; the wordmark's thin+bold mix looks odd; wants logo motion, a loader/motion while pages open, many more interactive animations (especially hover and items loading), and the mascot used in many more places. "For now the pages matter most."

**Spec / rules that still bind:** `docs/PLAN.md §2` honesty rules on every screen; `docs/decisions.md` 8 (light only, orange `#ee8a2a` active, black sheet) and 12 (motion system: `globals.css` tokens + `web/src/lib/motion.ts`, GSAP + CSS, `byKeyboard()`, reduced motion = no movement); no runtime loads from outside Iran (fonts self-hosted); RTL; phone-first, 44 px targets; e2e `honesty.spec`, `motion.spec`, catalog/consult specs must stay green.

## Global Constraints

- Every animation: transform/opacity only (no layout props), ≤ 400 ms for UI feedback (entrances may be up to 600 ms), `--ease-out` family, interruptible, and fully disabled under `prefers-reduced-motion: reduce` (content must be visible and final without motion). Hover effects only under `@media (hover: hover)`.
- Content is never hidden waiting for an animation: no section may render at opacity 0 if JS/IntersectionObserver fails (use CSS-first entrances or a `no-js`-safe fallback). The current landing shows near-invisible sections while scrolling — that must not happen.
- Contrast: body text ≥ 4.5:1 on its band, muted text ≥ 4.5:1 (darken `--color-ink-muted` if needed).
- Mascot images are decorative unless they carry meaning (`alt=""` + `aria-hidden`), sized with explicit width/height, `loading="lazy"` below the fold, never upscaled beyond 640 px.
- Don't change API contracts, data, or agent code. Web only (plus docs).
- Ponytail: smallest complete change; every shortcut gets a `ponytail:` comment.
